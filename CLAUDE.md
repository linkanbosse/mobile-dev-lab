# Mobile Development Rules

- Inspect the project before modifying files.
- Preserve existing functionality.
- Prefer minimal, targeted changes.
- Remove obsolete files only after verifying they are unused.
- Use Java and XML for native Android projects when requested.
- Use GitHub Actions for cloud builds.
- Run available tests after meaningful changes.
- Never claim a build succeeded without evidence.
- Use free tools and services only.
- Never commit tokens, passwords, or signing keys.
